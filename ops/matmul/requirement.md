# aten::matmul A1 需求

负责人：陶焱烽。任务表要求 FP32、FP16、BF16 的前向与反向分别验证。本阶段以 A1 在目标设备接管 `torch.matmul` / `aten::matmul`，核心计算使用自研 Triton；各硬件分别验收。

## 功能范围

| 输入 | 输出与要点 |
|---|---|
| 向量 @ 向量 | 标量点积 |
| 矩阵 @ 向量、向量 @ 矩阵 | 正确升维、降维 |
| 矩阵 @ 矩阵 | 常规 GEMM 与非整倍数尾块 |
| 批量矩阵 @ 批量矩阵 | 批次维广播和梯度归约 |

还需验证非连续 stride、零 K、空输出/空批次、零输入、较大输入、`K=1`、不合法形状、输入不被修改。反向分别验证左右输入梯度和单侧 `requires_grad`。仅支持 FP32/FP16/BF16 的一阶梯度；高阶梯度不在本期范围。

## 验收口径

- CPU FP32 内部计算并 cast 回输入 dtype，生成前向与双输入梯度黄金。
- 三 dtype、每用例三种子、GEMM 相对误差不超过 `5e-2`；零参考使用 dtype 绝对容差。
- kernel 直测与哨兵、A1 注册和实际命中、应用消费者对照均通过。
- 原生 PyTorch、自研 Triton、可用时的 FlagGems 用相同输入比较；不可用须记录具体原因。
- 性能按仓库的 20 次预热、最多 100 次采样、独立进程与完成读回口径，建立同环境基线并通过门禁。
- 昆仑芯、寒武纪、昇腾、壁仞分别出具证据；一台设备的通过不代表其他设备。
